# 🎮 RetroNova

**Современная игровая платформа:** 40+ классических браузерных игр, экономика Coins, магазин скинов, достижения, ежедневные задания, конструктор собственных игр на HTML/CSS/JS и игры сообщества.

## 🚀 Как запустить

### Вариант 1 — встроенный сервер (рекомендуется)

Нужен [Node.js](https://nodejs.org) (уже установлен, если вы читаете это в среде разработки).

```bash
cd site_nostalgia
node server.js
```

Откройте **http://localhost:8080** — готово.

### Вариант 2 — Python

```bash
cd site_nostalgia
python3 -m http.server 8080
```

Откройте **http://localhost:8080**.

### Вариант 3 — любой статический сервер

```bash
npx serve .
# или
npx http-server -p 8080
```

> ⚠️ **Не открывайте `index.html` двойным кликом** (протокол `file://`): браузеры блокируют часть возможностей (LocalStorage-политика, iframe-песочница, загрузка модулей). Используйте локальный сервер — это 1 команда.

**Требования:** современный браузер (Chrome, Firefox, Safari, Edge). Интернет не нужен — всё работает офлайн (шрифты подгружаются с Google Fonts, но есть системный fallback).

## 👤 Вход

1. Введите **любой ник** (2–20 символов).
2. Нажмите **«Войти»** — профиль создастся автоматически.
3. При повторном входе с тем же ником загружается существующий прогресс.

**Безопасность:** вход только по нику **не защищает** аккаунт от захвата другим человеком на этом устройстве. Данные хранятся в `LocalStorage` браузера. Для реальной многопользовательской версии нужен сервер и безопасная авторизация (пароль / OAuth / сессии).

## 🕹️ Что внутри

### 44 игры
Змейка, Змейка 2, Тетрис, Pac-Man, Понг, Space Invaders, Flappy Bird, Сапёр, 2048, Breakout, Арканоид, Doodle Jump, Дино Ран, Астероиды, Memory, Крестики-нолики, Шахматы, Шашки, Солитёр, Судоку, Четыре в ряд, Саймон, Молоток, Бомбермен, Лягушка, Galaga, Geometry Dash, Color Switch, Tower Defense, Cookie Clicker, Тест реакции, Скорость печати, Aim Trainer, Бесконечный бег, Гонки, Баскетбол, Пенальти, Мини-гольф, Пузыри, Match-3, Ракетная оборона, Пятнашки, Ловец, Морской бой.

Каждая игра:
- реально работает (canvas/DOM + полноценная игровая логика);
- имеет паузу (Esc / кнопка), перезапуск (R / кнопка) и полный экран;
- считает очки и сохраняет рекорды;
- поддерживает клавиатуру и мышь;
- адаптирована под тач (виртуальный D-pad, кнопки A/B, свайпы или тапы).

### Экономика Coins
| Действие | Награда |
|---|---|
| Завершить игру | +5 |
| Хороший результат (порог у каждой игры) | +10 |
| Новый рекорд | +20 |
| Ежедневный вход | +15 |
| Задание дня | +15–60 |
| Достижение | +20–250 |
| Публикация игры | +25 |

Защита от накрутки: награда за игру выдаётся только за реальный забег (минимум 6 секунд), с кулдауном на частые перезапуски; ежедневная награда — строго раз в календарный день (обновление страницы не помогает). Все траты и начисления видны в истории профиля.

### Магазин и скины
32 предмета: 8 тем, 8 акцентных цветов, 5 фонов, 8 цветов змейки, 6 рамок аватара, 6 UI-эффектов. Редкости Common / Rare / Epic / Legendary. Покупка и применение работают мгновенно, предметы остаются в инвентаре навсегда.

### Конструктор игр
- Файловый менеджер: создание/удаление HTML, CSS, JS файлов.
- Редактор с подсветкой синтаксиса, номерами строк, автосохранением.
- Запуск в изолированном **sandbox iframe** (`sandbox="allow-scripts"`) — код не имеет доступа к основному сайту.
- Консоль ошибок и `console.log` из iframe через `postMessage`.
- Полноэкранный предпросмотр.
- Готовые шаблоны: пустой проект, Ловец, Кликер, Змейка.
- Кнопки «Запустить», «Сохранить», «Сбросить».

### Игры сообщества
- Публикация с названием, описанием и обложкой.
- Автомодерация: стоп-слова, лимит размера, проверка на сетевые запросы и подозрительный код (такие проекты уходят на ручную проверку).
- Лайки, избранное, счётчик запусков, жалобы (3 жалобы → автоскрытие).
- «Ремикс»: копирование чужой игры в свой проект для доработки.
- 2 демо-игры от команды RetroNova для примера.

### Прочее
- 25 достижений, 3 ежедневных задания, серия входов.
- Таблица лидеров по Coins / уровню / играм / рекордам / очкам.
- Профиль с уровнем, XP, статистикой, историей Coins, графиком активности.
- Экспорт/импорт прогресса в JSON.
- Адаптив: ПК, ноутбуки, планшеты, смартфоны (нижняя навигация, крупные тач-кнопки).

## 🗂️ Структура проекта

```
site_nostalgia/
├── index.html              # точка входа (SPA)
├── server.js               # локальный статический сервер (0 зависимостей)
├── css/
│   ├── base.css            # переменные, темы, кнопки, типографика
│   ├── layout.css          # сайдбар, топбар, адаптив
│   ├── components.css      # карточки, модалки, тосты, таблицы
│   ├── pages.css           # стили страниц
│   ├── game-shell.css      # HUD игр, пауза, тач-контролы
│   └── editor.css          # редактор кода и предпросмотр
├── js/
│   ├── core/
│   │   ├── store.js        # профили, LocalStorage, экономика данных
│   │   ├── ui.js           # тосты, модалки, конфетти
│   │   ├── economy.js      # Coins, анти-накрутка, уровни
│   │   ├── achievements.js # 25 достижений
│   │   ├── quests.js       # ежедневные задания
│   │   ├── shop.js         # каталог предметов
│   │   ├── skins.js        # применение скинов
│   │   ├── sfx.js          # WebAudio-синтезатор
│   │   ├── router.js       # hash-роутер
│   │   ├── games.js        # реестр игр + игровой шелл + input kit
│   │   ├── projects.js     # проекты, шаблоны, сборка sandbox-документа
│   │   └── moderation.js   # автопроверка публикаций
│   ├── pages/              # 13 страниц платформы
│   ├── games/              # 44 игровых модуля
│   └── app.js              # загрузка приложения
└── tests/
    └── smoke.js            # автотесты всех игр в headless Chrome
```

**Архитектура:** vanilla JS без сборки, модули через IIFE + глобальный namespace `RN`. Каждая игра — отдельный файл, регистрируется через `RN.games.register(meta, factory)` и получает общий API (input, canvas, loop, pause, gameOver, coins).

## 🧪 Тесты

```bash
cd tests
npm install            # puppeteer-core
node smoke.js          # все игры + страницы + экономика + редактор + мобильный вид
```

Тест открывает Chrome headless, проверяет загрузку каждой игры, отсутствие JS-ошибок, работу паузы, начисление Coins, покупку/применение скина, sandbox-редактор и адаптив.

## ⚠️ Ограничения локальной версии

- Профили, рейтинг и игры сообщества хранятся **на одном устройстве** (LocalStorage). Это не глобальный мультиплеер.
- Вход по нику небезопасен по дизайну (см. выше) — добавьте серверную авторизацию для продакшена.
- Публикация игр проходит автопроверку; полноценная модерация требует бэкенда.
- Для переноса прогресса используйте «Настройки → Экспорт/Импорт».
